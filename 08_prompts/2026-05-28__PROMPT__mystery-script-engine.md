# Mystery Script Engine v2

**Prompt maître** pour générer n'importe quel script mystery en 30 secondes.

**Variables** : [THEME], [DURÉE], [TWIST_TYPE]

**Exemple d'utilisation** :
"Génère un script [DURÉE=60s] sur [THEME=appel 911] avec twist [TWIST_TYPE=personne n'a appelé]"

**Règle d'or** : Le twist doit toujours remettre en question la réalité de l'histoire ("et si tout ça n'était qu'une illusion ?").

**Bonus** : Ajoute toujours 1 "easter egg" pour les vrais fans (détail qui relie à un autre dossier).
