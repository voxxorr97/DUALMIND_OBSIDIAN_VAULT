# Content-to-Cash Loop

**Le moteur de revenu passif de DualMind** :

1. **Idée** (10_ideas) → Hermes CEO filtre
2. **Script** (08_prompts) → Mystery Script Engine
3. **Visuel** (03_content + hallmark) → Thumbnails + scènes
4. **Montage** (ffmpeg skill) → Vidéo finale
5. **Publication** (YouTube/TikTok auto)
6. **Analyse** (09_analytics) → Ce qui marche ?
7. **Produit** (14_monetisation) → Transformer le hit en pack prompts
8. **Boucle** : Le hit finance le scaling

**Règle** : Chaque vidéo doit pouvoir devenir un produit digital dans les 7 jours.
